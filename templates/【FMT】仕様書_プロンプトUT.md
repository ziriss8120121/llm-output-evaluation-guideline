# 【FMT】仕様書_プロンプトUT

## 目的

観点シートで定義した評価観点について、実際に評価・採点・合否判定するための評価基準と合格基準を定義する仕様書。

|  |  |  |

## 評価基準の標準フォーマット

評価基準は、以下の形式で5〜1の判定条件をすべて記載する。

```text
5. 〇〇
4. 〇〇
3. 〇〇
2. 〇〇
1. 〇〇
```

各段階は、隣接する評価値との違いが評価者に判断できる粒度で記載する。

## 合格基準の考え方

合格基準の具体値は案件ごとに設定する。

少なくとも、以下を検討する。

- 評価件数（n）
- 平均評価値等の集計基準
- 評価値1等の重大NGを許容するか
- 特定の観点を必須合格とするか

### 記入例

```text
n=10、平均評価値3.0以上、かつ評価1が0件
```

上記は標準の合格基準ではなく、案件ごとに合格基準を設定する際の記入例とする。

## 記入例

スカウト文面自動生成（入力：求人票）の場合。

| 観点No | 評価基準 | 合格基準 |
|---:|---|---|
| 1 | **5.** 求人条件がすべて正確に反映され、矛盾・誤認につながる表現がない。<br>**4.** 求人条件は正確に反映されており、本質に影響しない軽微な表現差のみ存在する。<br>**3.** 一部に軽微な不足・曖昧さがあるが、候補者の求人理解や判断に影響しない。<br>**2.** 求人条件の一部に明確な誤り・矛盾・誤解を招く表現がある。<br>**1.** 年収、勤務地、雇用条件等の重要条件に重大な虚偽・矛盾がある。 | n=10、平均評価値3.0以上、かつ評価1が0件 |
| 2 | **5.** 求人票にない情報を事実として追加していない。<br>**4.** 求人票の情報を自然に言い換えているのみで、新たな事実の追加はない。<br>**3.** 一部に推測的な表現があるが、推測であることが明確で誤認につながらない。<br>**2.** 求人票にない情報を事実と受け取れる形で一部記載している。<br>**1.** 求人票にない重要な条件・制度・待遇を存在するものとして明確に記載している。 | n=10、平均評価値3.0以上、かつ評価1が0件 |

## 記入完了条件

- 観点シートに存在するすべての観点Noが、仕様書から1件ずつ参照されている。
- すべての観点に5〜1の評価基準が定義されている。
- すべての観点に合格基準が定義されている。
- すべての観点から、観点No → 完了条件Noの順に上位工程まで遡れる。
- 観点シートに存在しない観点Noを参照していない。
