# 【FMT】観点シート_プロンプトUT

## 目的

完了条件シートで「対象」とした完了条件について、案件固有の評価観点へ具体化するためのシート。

## 観点シート

| 観点No | 完了条件No | 観点 | 観点の説明 |
|---:|---:|---|---|
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

## 記入例

スカウト文面自動生成（入力：求人票）で、完了条件No「3：誤情報・誤誘導」を対象とした場合。

| 観点No | 完了条件No | 観点 | 観点の説明 |
|---:|---:|---|---|
| 1 | 3 | 求人条件の事実性 | 求人票に記載された年収、勤務地、雇用条件等と生成されたスカウト文面の内容が矛盾していないかを確認する。 |
| 2 | 3 | 未記載情報の生成 | 求人票に存在しない条件、制度、待遇等を事実として生成していないかを確認する。 |
| 3 | 3 | 誤認を招く表現 | 直接的な虚偽ではなくても、候補者が求人条件を誤って認識する表現になっていないかを確認する。 |

## 記入完了条件

- 完了条件シートで「対象」としたすべての完了条件に、1件以上の観点が紐付いている。
- すべての観点に完了条件Noが付与されている。
- すべての観点が、仕様書の観点Noから1件ずつ参照されている。
- 完了条件シートに存在しない完了条件Noを参照していない。
